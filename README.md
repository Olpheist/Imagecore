# Project Setup

## Frontend
Directory: `client`

Requires: Node.js v24
```bash
npm install
npm run dev
```

## Backend
Directory: `server`


Requires: Java 17

1. Link or open the Gradle project
2. Start the development database by running `docker-compose-dev.yml` as a container
3. Run the Spring Boot application from the Gradle project
